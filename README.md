# Govnr Website

Public GitHub Pages website for the Govnr civic platform.

This repository is the organization Pages project for `Govnr`. Content published from the `master` branch is available at:

```text
https://govnr.github.io/
```

The site uses Jekyll with a lightweight custom theme.

## Local Preview

```sh
bundle install
bundle exec jekyll serve
```

Then open:

```text
http://localhost:4000
```
