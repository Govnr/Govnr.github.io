## Join the discussion

Questions, ideas, and early feedback belong in the [Govnr organization discussions](https://github.com/orgs/Govnr/discussions). That is the main place to talk about direction, priorities, and how the platform should work for real groups.

## Contribute to development

Code and technical work live across the [Govnr repositories on GitHub](https://github.com/Govnr). The core platform, web apps, documentation, and verification tools are separate projects with their own README files and issue trackers.

If you want to contribute:

- read the relevant repository README first;
- open or join a discussion before large changes;
- keep pull requests focused and easy to review.

You do not need to be a full-time developer to help. Clear issue reports, documentation improvements, and thoughtful design feedback are valuable too.

## Sponsor us

Govnr is actively seeking sponsorship. Financial and in-kind support helps us build and maintain open civic infrastructure that groups can trust for fair, verifiable participation.

If your organisation or foundation would like to support this work, please [start a conversation in our discussions](https://github.com/orgs/Govnr/discussions) or reach out through the [Govnr organization on GitHub](https://github.com/Govnr).

## Stay in the loop

Project notes are published on the [Updates](/updates/) page as the platform build progresses.
